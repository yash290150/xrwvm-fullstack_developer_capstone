# Full Stack Car Dealership Application

## Project Name
Car Dealership Review Portal

## Project Description
This project is a full-stack web application for browsing car dealerships,
viewing dealer information, filtering dealers by state, viewing customer
reviews, and submitting new reviews.

The application provides user registration and login functionality and
allows authenticated users to review car dealerships.

## Technologies Used
- Django
- Python
- React
- JavaScript
- Node.js
- Express
- REST APIs
- SQLite
- MongoDB
- HTML5
- CSS3
- Bootstrap
- GitHub Actions

## Main Features
- User registration
- User login and logout
- View all dealerships
- Search dealerships by state
- View dealer details
- View dealer reviews
- Submit dealer reviews
- Car makes and models
- Review sentiment analysis
- Django administration
- CI/CD using GitHub Actions
- Cloud deployment
